# text2img：文字转图片

将文字转换为高清晰度图片的纯前端工具。输入文本即可实时预览生成效果，支持自定义字体、颜色、对齐方式、渐变/图片背景，并提供多格式、多倍率导出与 IPFS 图床上传。

> 纯静态、零依赖、可自行部署。无构建步骤，浏览器直接打开 `index.html` 即可使用（建议通过本地 HTTP 服务访问以完整使用所有功能）。

## 功能特性

### 文本
- 实时预览：输入文本即生成（500ms 节流），`Ctrl+Enter` 手动生成
- 支持多行文本与空行，可设置每行最大字符数自动换行
- 对齐方式：左对齐 / 居中 / 右对齐
- 文字大小（输出像素实时换算提示）、行间距、边距
- 字体：内置 17 种中文字体 + 12 种英文字体，可按需动态加载 Google Fonts（Noto、站酷、思源等 24 款）
- 正方形图片模式（文字垂直居中）

### 背景
- 纯色/线性渐变背景（起止色 + 角度 + 透明度）
- **透明背景**（勾选后导出 PNG 保留透明通道）
- 背景图片：文件选择或**直接拖拽到预览区**，支持 cover / contain / stretch / tile 四种适配模式

### 导出
- 格式：PNG（无损）/ JPEG / WebP，JPEG 与 WebP 可调质量
- 倍率：1x / 2x / 3x 高清导出（离屏渲染，不影响预览流畅度）
- 文件名自定义，下载自动追加对应扩展名
- 状态栏实时显示输出尺寸（宽 × 高 px）、格式与估算文件大小

### 图床
- 一键上传 IPFS，成功后自动生成普通 / Markdown / HTML 三种链接，点击即复制
- 多网关 seeding 加速文件分发
- 上传失败自动重试 3 次

### 交互细节
- 预览区三种缩放模式：适应 / 100% / 200%，点击画布可放大查看（支持滚轮缩放、双击还原、ESC 关闭）
- 拖拽 `.txt` 文本文件到输入框自动导入内容
- 设置自动保存到 `localStorage`，刷新不丢失
- 字体切换后等待字体加载完成再重绘，避免样式跳变
- 明暗主题跟随系统（`prefers-color-scheme`）

## 使用方法

1. 在左侧输入文本
2. 按需调整文本 / 背景 / 导出设置（右侧预览实时更新）
3. 点击「下载图片」保存，或「上传到图床」生成在线链接

## 部署

本项目为纯静态页面，可部署到任意静态托管：

```bash
# 本地预览
python -m http.server 3000
# 访问 http://localhost:3000
```

也可直接部署到 GitHub Pages、Vercel、Netlify 等平台。

## 技术说明

- 无任何外部运行时依赖（IPFS 上传使用原生 `fetch`）
- 渲染基于 Canvas 2D，默认 10x 逻辑缩放保证文字清晰
- 高清导出通过离屏 Canvas 按倍率重绘实现
- 通过 `document.fonts.load` 确保 Google 字体就绪后再生成
